# AI Placement Assistant

An Agentic AI application that analyzes a candidate's resume against a job description.

## Features

- Resume skill analysis
- Job requirement analysis
- Skill matching
- Missing skill identification
- Improvement suggestions
- Interview question generation
- Final placement analysis report

## Technology

- Python
- LangChain
- LangGraph
- Google Gemini
- python-dotenv

## Architecture

Resume → Job Analysis → Skill Matching → Gap Analysis → Improvement Planning → Interview Generation → Final Report
